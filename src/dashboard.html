        Cloudflare 연결
        
            
          
          1. API 토큰 화면 → Create Token → Custom token.
            2. 
          
          2. 권한은 Account · Billing · Read 하나만 넣어요. 청구 내역만 볼 수 있는 토큰이에요.
            3. 
          
          3. 만든 토큰을 아래에 붙여 넣어요. 계정이 여러 개면 계정 ID도 넣어요(대시보드 주소 dash.cloudflare.com/계정ID).
            4. 
        
          
        
        
        
          Cloudflare는 한 달에 한 번 청구돼서, 월말 예상은 지난달 청구액 기준으로 보여 줘요.
          
      
          

      
          
        GitHub 연결
        
            
          
          1. Fine-grained 토큰 만들기 → Account permissions에서 Plan: Read-only만 켜요. 저장소 권한은 없어도 돼요.
            2. 
          
          2. 조직 비용을 보려면 조직 이름을 넣어요. 그 조직의 관리자여야 해요.
            3. 
          
          3. GitHub의 새 청구 플랫폼을 쓰는 계정에서만 읽혀요. 안 되면 아래 "요금제로 직접 기록"을 써 주세요.
            4. 
        
          
        
        
      
          

      
          
        Vercel 연결

            2. 
          
          2. Vercel에는 읽기 전용 토큰이 없어서 이 토큰은 그 팀을 다룰 수 있어요. 이 확장은 청구 조회만 하지만 공용 PC에서는 연결하지 마세요.
            3. 
          
          3. 팀에서 Owner·Billing처럼 청구를 볼 수 있는 역할이어야 해요.
