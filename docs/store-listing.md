# 크롬 웹스토어 등록 문안 (v0.6.0)

웹스토어 개발자 대시보드에 그대로 붙여 넣는 문안이에요. 실제 업로드와 개발자 계정 등록은 사람이 직접 해요.

## 짧은 소개

> 결제수단을 어디에 등록했고 매달 얼마 나가는지 자동으로 기록해요. 서버·API 사용료도 매일 아침 모아 보여줘요.

## 자세한 설명

결제 기록장은 "그 카드, 어디에 등록했더라?"와 "이번 달에 얼마 나가지?"에 답하는 확장프로그램이에요.

주요 기능
- 결제 자동 기록: 결제 페이지에서 카드번호 입력칸과 결제 버튼 클릭을 감지해 사이트, 금액, 주기, 카드 끝 4자리를 기록해요.
- 이번 달 한눈에 보기: 구독과 일회성 결제를 월별로 모으고, 달마다 그래프로 비교해요.
- 빠른 추가: 자주 쓰는 구독을 골라 담아 바로 기록해요.
- 카드 이용내역 가져오기: 카드사 이용내역 파일(CSV)을 고르면 브라우저 안에서만 읽어, 여러 달 반복된 결제를 "확인할 기록"으로 넣어요. 파일 원문은 저장하거나 보내지 않아요.
- 구독 계정 페이지 읽기: Netflix·YouTube Premium·Spotify·Claude·GitHub의 결제 화면을 열면 요금제·가격·다음 결제일을 읽어 "결제 기록장에 추가할까요?"라고 물어요. 누르기 전에는 저장하지 않아요.
- 내 카드: 카드 브랜드와 끝 4자리에 이름을 붙여 어떤 카드가 어디에 등록됐는지 봐요.
- 결제일 알림: 결제일과 체험 종료 전에 알려 줘요.
- 서버·API 사용료: AWS, OpenAI, Cloudflare, GitHub, Vercel의 사용료를 매일 아침 한 번 조회해 한 화면에 합쳐 보여줘요. 읽기용 키만 쓰면 돼요.

개인정보
- 개발자 서버가 없어요. 모든 기록과 연결 키는 내 브라우저 안(chrome.storage.local)에 저장돼요.
- 크롬 동기화(기본은 꺼짐)를 켜면 기록·카드·설정을 같은 구글 계정의 크롬끼리 맞춰요. 연결 키는 동기화하지 않아요.
- 전체 카드번호, 유효기간, CVC, 비밀번호는 저장하지 않아요.
- 광고와 분석 도구를 쓰지 않아요.
- AWS Cost Explorer는 조회 1번에 0.01달러를 내 AWS 계정에 청구해요. 자동 조회는 하루 한 번으로 제한해요.

## 단일 목적

결제수단 등록과 구독 결제를 자동으로 기록하고, 사용자가 연결한 서비스의 사용료를 모아 보여주는 개인용 결제 기록장이에요.

## 권한별 사유

| 권한 | 사유 |
|------|------|
| `storage` | 결제 기록, 내 카드, 설정, 연결 키를 브라우저에 저장해요. 사용자가 동기화를 켜면 기록·카드·설정만 크롬 동기화에도 저장해요. |
| `webNavigation` | 결제창 팝업이나 결제대행사 이동을 원래 사이트의 기록으로 묶어요. |
| `alarms` | 매일 아침 사용료 갱신과 결제일 알림 시각을 맞춰요. |
| `scripting` | 사용자가 연결 화면의 버튼으로 연 서비스 콘솔 탭 하나에서만, 새로 만든 토큰을 읽어 자동으로 채워 줘요. 다른 탭에는 쓰지 않아요. |
| `notifications` | 결제일과 체험 종료 알림을 보여줘요. |
| `<all_urls>` | 어느 사이트에서 결제했는지 알려면 결제 페이지가 어디인지 미리 정할 수 없어서 모든 페이지에서 카드번호 입력칸과 결제 버튼 클릭만 감지해요. 페이지 본문은 저장하거나 보내지 않아요. 토큰 자동 받기와 사용료 조회를 위해 각 서비스의 공식 주소에도 접근해요. 구독 계정 페이지(넷플릭스·유튜브 프리미엄·스포티파이·Claude·GitHub 결제 화면)에서만 요금제·가격·다음 결제일을 읽어요. |

## 데이터 사용 공개

수집하는 데이터 유형 체크 답안
- 금융 및 결제 정보: 체크해요. 카드 브랜드와 끝 4자리, 결제 금액, 결제 주기만 저장해요. 전체 카드번호, 유효기간, CVC는 저장하지 않아요.
- 인증 정보: 체크해요. 사용자가 직접 연결한 서비스의 읽기용 키 또는 로그인 토큰을 브라우저 안에만 저장해요.
- 웹 기록: 체크해요. 결제가 일어난 사이트의 도메인을 기록해요.
- 사용자 활동: 체크해요. 결제 버튼 클릭과 카드번호 입력칸 감지만 써요.
- 이용내역 파일: 사용자가 고른 카드사 이용내역 파일은 브라우저 안에서만 읽어요. 파일 원문은 저장하거나 보내지 않고, 반복 결제로 찾은 가맹점·금액·날짜 후보만 저장해요.
- 개인 식별 정보, 건강 정보, 개인 커뮤니케이션, 위치, 웹사이트 콘텐츠: 체크하지 않아요. 페이지 본문은 저장하지 않아요.

인증 항목 (세 가지 모두 체크해요)
- 승인된 사용 사례 외에는 사용자 데이터를 제3자에게 판매하거나 전송하지 않아요.
- 항목의 단일 목적과 무관한 목적으로 사용자 데이터를 사용하거나 전송하지 않아요.
- 신용도 판단이나 대출 목적으로 사용자 데이터를 사용하거나 전송하지 않아요.

원격 코드: 쓰지 않아요. 모든 코드는 패키지 안에 들어 있어요.
