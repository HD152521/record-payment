결제 기록장 개인정보 처리방침

시행일 2026년 11월 16일 · 대상: 크롬 확장프로그램 "결제 기록장"

요약 · 결제 기록장은 개발자 서버가 없습니다. 모든 기록과 연결 키는 사용자의 브라우저 안에만 저장되고, 개발자를 포함한 누구에게도 보내지 않습니다. 광고·분석 도구도 쓰지 않습니다.

1. 저장하는 정보

아래 정보는 모두 브라우저의 확장프로그램 저장소(chrome.storage.local)에만 저장됩니다.

  • 결제 기록: 사이트 도메인, 날짜, 유형(구독·일회성·결제수단 등록), 결제 주기, 금액, 결제대행사 이름, 카드 브랜드와 끝 4자리, 사용자가 적은 메모
  • 내 카드: 카드 브랜드, 끝 4자리, 사용자가 붙인 이름
  • 설정: 월 예산, 결제 알림 설정
  • 서버·API 사용료 연결: 사용자가 직접 연결한 서비스(AWS·OpenAI·Cloudflare·GitHub·Vercel)의 읽기용 키 또는 로그인 토큰, 그리고 받아 온 사용료 숫자와 원/달러 환율

저장하지 않는 정보: 전체 카드번호, 유효기간, CVC, 비밀번호, 방문한 페이지의 본문.

2. 웹페이지에서 읽는 것

  • 결제 순간을 자동으로 기록하려고 모든 페이지에서 카드번호 입력칸과 결제 버튼 클릭만 감지합니다. 그때 화면 글자에서 금액·주기·구독 여부를 뽑고, 카드번호 입력칸에서는 끝 4자리만 남깁니다. 페이지 원문은 저장하거나 보내지 않습니다.
  • 토큰 자동 받기: 사용자가 연결 화면의 버튼으로 연 탭 하나에서만, 그 서비스의 공식 콘솔(예: platform.openai.com, github.com)에 새로 만든 토큰이 보이면 그 값을 읽습니다. 사용자가 "연결하기"를 누르기 전에는 저장하지 않으며, 다른 탭과 사이트는 읽지 않습니다.

3. 외부로 보내는 요청

개발자가 운영하는 서버는 없습니다. 확장프로그램은 아래 주소로만 직접 요청합니다.

언제어디로무엇을
사용자가 사용료를 연결했을 때연결한 서비스의 공식 API만
ce.us-east-1.amazonaws.com, api.openai.com, api.cloudflare.com, api.github.com, github.com(로그인), api.vercel.com		사용자가 넣은 키·토큰으로 그 계정의 사용료를 조회합니다. 키는 해당 서비스에만 보냅니다.
달러 금액을 원화로 합칠 때open.er-api.com공개 환율 조회. 사용자 정보는 보내지 않습니다.

저장된 정보를 판매하거나 제3자와 공유하지 않으며, 광고·신용평가·대출 심사 등 확장프로그램 기능과 무관한 목적으로 쓰지 않습니다.

4. 사용료 조회 비용 (AWS)

AWS Cost Explorer API는 조회 1번에 미화 0.01달러를 사용자의 AWS 계정에 청구합니다. 결제 기록장은 자동 조회를 하루 한 번으로 제한하며(한 달 약 0.30달러), "지금 갱신"을 누를 때마다 0.01달러가 추가됩니다. 이 비용은 AWS가 청구하며 결제 기록장은 어떤 돈도 받지 않습니다. 다른 서비스의 사용료 조회 API는 무료입니다.

5. 보관과 삭제

  • 정보는 사용자가 지우기 전까지 브라우저에 남습니다.
  • 설정 화면의 모든 데이터 지우기로 기록·카드·연결 키를 한 번에 지울 수 있습니다.
  • 사용료 연결을 해제하면 그 서비스의 키·토큰이 바로 지워집니다.
  • 확장프로그램을 삭제하면 저장된 정보도 모두 지워집니다.
  • 설정의 백업 파일에는 연결 키·토큰이 들어가지 않습니다.

English summary

Payment Tracker has no developer server. All records, card brand and last 4 digits, settings and the read-only keys you connect are stored only in your browser (chrome.storage.local). Requests go only to the official APIs of services you choose to connect and to a public exchange-rate API (open.er-api.com). We do not sell, share or transfer user data to third parties, do not use it for purposes unrelated to the extension's single purpose, and do not use it for creditworthiness or lending. The use of information complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. AWS Cost Explorer charges $0.01 per request to your own AWS account; automatic refresh is limited to once a day.
