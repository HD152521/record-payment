# 결제 기록장 (크롬 확장프로그램)

결제하거나 카드를 등록할 때마다 **어느 사이트에서 / 구독인지 일회성인지 / 얼마인지 / 어떤 카드로**를 자동으로 기록하고, 이번 달 나가는 돈을 한눈에 보여줍니다.

**AWS · Azure · OpenAI · Cloudflare · GitHub · Vercel** 계정을 연결하면 이번 달 사용료·월말 예상·지난달을 매일 아침 가져와 원화로 합쳐 보여줍니다.

## 화면

대시보드는 화면마다 큰 기능 하나만 둡니다. 위 막대에서 옮겨 다니고, **＋ 추가**는 어느 화면에서나 눌러요.

| 화면 | 주인공 | 곁들인 것 |
|---|---|---|
| 이번 달 | 이번 달 나가는 돈 | 지난달 대비, 구독·일회성·서버 구성 막대, 예산 막대, 확인할 기록, 30일 안 결제 예정 |
| 달마다 | 달별로 쌓은 막대 그래프(6·12개월) | 표로 보기, 기간 합계·월 평균·가장 많이 쓴 달, 많이 쓴 곳 5곳 |
| 기록 | 전체 기록 표 | 유형 필터, 검색, CSV 내보내기 |
| 서버·API | 이번 달 사용료 | 연결별 카드, 연결 추가·갱신 |
| 카드 | 내 카드 목록 | 카드별 월 합계 |
| 설정 | — | 월 예산, 결제 알림, 백업·복원, 모든 데이터 지우기 |
| 사용법 | 기본 3단계 | 다른 기능, 잘 안 될 때 |

- **달마다 그래프**는 기록에서 결제일을 다시 계산해서 그려요. 서버·API 사용료는 연결한 뒤부터 달마다 쌓여요(`cloudHistory`, 24개월). 이번 달 막대는 남은 결제일까지 포함한 예상이라 옅게 보여요.
- **월 예산**: 이번 달 돈이 예산의 80%를 넘으면 ⚠, 넘으면 ⛔로 보여 줘요.
- **결제 알림**: 켜면 매일 아침 9시(또는 브라우저를 켤 때) 며칠 안에 결제되는 구독과 끝나는 무료 체험을 크롬 알림으로 알려요. 같은 결제일은 한 번만 알려요. **예시 알림**이 안 보이면 컴퓨터의 알림 센터(Windows는 `Win+N`)를 열어 보고, 방해 금지와 Chrome 알림 설정을 확인해 주세요. 크롬에서 이 확장의 알림이 막혀 있으면 "보냈어요" 대신 막혀 있다고 알려요.
- **안내 메시지**: 설정 화면의 결과 안내는 화면 아래에 잠깐 뜨고, 긴 문구는 더 오래(최대 12초) 남아요.
- **카드 이용내역 가져오기**: 카드사 이용내역 CSV(엑셀은 CSV로 저장)를 고르면 브라우저 안에서만 읽어, 같은 가맹점이 비슷한 금액(±10%)으로 매달·매년 반복된 결제를 "확인할 기록"으로 넣어요. 신한·삼성·현대·KB 양식은 **공개된 일반 형태를 가정**해 만들었고(시험 파일은 `test/fixtures/`의 가짜 데이터), 다른 양식은 열 고르기로 받아요. 파일 원문은 저장하지 않아요.
- **구독 계정 페이지 읽기**: Netflix·YouTube Premium·Spotify·Claude·GitHub의 결제 화면을 열면 요금제·가격·다음 결제일을 읽어 "결제 기록장에 추가할까요?" 안내를 띄워요. 추가를 눌러야 "확인할 기록"으로 저장하고, 거절하면 그 사이트는 30일 동안 다시 묻지 않아요. 못 읽는 화면에서는 조용히 넘어가요.
- **백업·복원**: 기록·카드·설정을 `.json`으로 받아요. 사용료 연결 키는 넣지 않아요. 가져올 때 기록을 하나씩 다시 검사하고, 같은 기록은 파일 값으로 바꿔요.
- **모든 데이터 지우기**: "지우기"를 입력해야 지워져요. 서비스에서 만든 토큰은 그쪽에서도 지워 주세요.

## 설치

1. 크롬 주소창에 `chrome://extensions` 입력
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`payment-tracker`) 선택
4. 툴바 퍼즐 아이콘에서 "결제 기록장"을 고정

기록되면 아이콘에 잠깐 `✓` 배지가 뜹니다. 팝업에서 요약을 보고, **전체 대시보드 열기**로 전체 목록·수정·CSV 내보내기를 할 수 있습니다.

## 합계 규칙

- **확인한 기록만 셉니다.** 결제 화면에서 자동으로 적은 기록은 결제 "시도"라서 **확인할 기록**에 먼저 모여요. "맞아요"를 누르거나 고쳐서 저장하면 합계에 들어가고, "아니에요"를 누르면 지워져요. 무료 체험은 "맞아요"를 누를 때 체험이 끝나는 날을 받아요.
- **큰 숫자는 이번 달 실제로 나가는 돈**이에요. 이번 달에 결제일이 든 구독, 이번 달 일회성 결제, 서버·API 월말 예상을 더해요. 연간 구독은 결제하는 달에만 전액이 잡히고, 월 평균(연간은 ÷12)은 아래에 작게 보여요.
- **같은 돈은 한 번만 셉니다.** 사용료 연결이 된 서비스(AWS·Azure·OpenAI·Cloudflare·Vercel)를 직접 기록해 두었으면 그 기록은 합계에서 빼고 "연결 값에 포함"이라고 표시해요. GitHub는 요금제·Copilot이 사용량 보고서에 들어가는지 확인 전이라 빼지 않아요.
- **첫 결제일**부터 주기마다 결제일을 셉니다. 무료 체험이면 체험이 끝나는 날을 첫 결제일로 넣어 주세요. 결제 예정 목록에 "체험 끝"으로 표시돼요.
- **해지**하면 해지한 날까지의 결제는 이번 달 금액에 남고, 그 뒤 결제일은 빠져요. 해지 뒤 지나간 결제일만큼은 "해지로 올해 아낀 돈"에 쌓여요. 해지일은 상태를 바꿔 저장한 날이에요.

## 추가하기 · 내 카드

- 대시보드의 **추가**를 누르면 서버·클라우드 / AI / 개발 도구 / 업무 도구 / 생활 구독 목록이 떠요. 한글로 검색해도 돼요(넷플, 커서…).
- **여러 개를 한 번에**: 목록에서 누르는 곳마다 아래 "고른 곳"에 담겨요. 요금제·결제 카드·첫 결제일(오늘·어제·이번 달 1일·날짜 고르기)을 칩으로 누르고 **N개 추가**를 누르면 끝이에요. 타자는 요금제가 없는 곳의 금액(선택)뿐이에요.
- 결제 카드는 사용 중인 구독에 가장 많이 쓴 카드(없으면 한 장뿐인 카드)를 미리 골라 둬요.
- 추가·삭제 뒤 아래에 뜨는 알림의 **되돌리기**로 바로 취소할 수 있어요. 그래서 기록 삭제는 묻지 않고 바로 지워요.
- 하나만 담고 **자세히 입력**을 누르면 요금제가 채워진 전체 양식으로 가요. 양식도 유형·주기·통화·카드·결제일을 칩으로 고르고, 상태·결제대행·메모는 "더 보기" 안에 있어요.
- AWS·Azure·OpenAI·Cloudflare·GitHub·Vercel은 담지 않고 바로 사용료 자동 연결 화면으로 가요. 연결이 안 되는 계정은 연결 화면의 "요금제로 직접 기록"을 쓰면 돼요.
- 요금제 가격은 `src/lib/catalog.js`의 `PRICES_AS_OF` 기준 참고가예요. 가격이 바뀌면 이 파일만 고치면 돼요.
- **내 카드**: 끝 4자리와 종류(칩)만 있으면 등록돼요. 별명은 선택이에요. 카드번호 전체·CVC·유효기간은 받지 않아요. 카드별 월 합계가 보여요. 끝 4자리가 같은 카드는 한 장으로 다뤄요.
- **카드 안 정한 기록**: 고른 기록에 카드를 한 번에 붙여요. 그 창의 **＋ 카드 등록**으로 새 카드를 만들면 바로 골라져 있고, 체크를 푼 기록은 그대로 빠져 있어요.
- 달러 구독을 원화로 합치려고 대시보드를 열 때 `open.er-api.com`에서 원/달러 환율을 받아요(12시간에 한 번, 실패하면 10분 뒤 재시도). 이 요청에는 기록·카드 정보가 실리지 않아요.

## 서버·API 사용료 (AWS · Azure · OpenAI · Cloudflare · GitHub · Vercel)

대시보드 **연결 추가**를 누르면 연결 마법사가 열려요. **1) 서비스 고르기 → 2) 버튼 하나로 토큰 만들기 화면 열기 → 3) 자동으로 받거나 붙여 넣기** 순서예요. 서비스마다 3~5단계 안내서와 바로가기 링크가 같이 보여서, 자동 받기가 안 돼도 안내서만 보고 끝까지 갈 수 있어요. 저장 전에 실제로 한 번 불러 보고, 틀리면 이유를 알려 줘요.

**연결 방식** (자세한 근거는 `docs/plan/easy-connect.md`)

- **A. 토큰 자동 받기**: 이미 로그인된 콘솔에서 토큰 만들기 화면을 열어 줘요(되는 곳은 권한까지 채워서). 사용자가 직접 만들기를 누르면 완료 화면에 뜬 토큰을 읽어 "이 토큰으로 연결할까요?"라고 물어요. 연결 버튼으로 연 그 탭만 읽고, 확인 전에는 저장하지 않아요.
- **B. 로그인으로 연결**: 서비스 로그인 화면에서 허용만 누르면 돼요. 확장에 비밀키(client secret)는 없어요.
- **C. 원클릭 만들기**: AWS CloudFormation 템플릿으로 비용 조회만 되는 IAM 사용자를 한 번에 만들어요.
- **D. 단계별 안내서 + 붙여넣기**: 모든 서비스에 있어요. A·B·C가 안 될 때 쓰는 기본 길이에요.

| 서비스 | 연결 방식 | 버튼이 여는 화면 | 필요한 권한 | 비용 |
|---|---|---|---|---|
| AWS | **C**(템플릿 S3 주소가 있을 때) 또는 **D**(템플릿 파일 올리기) + 액세스 키는 **A** | CloudFormation 스택 만들기 → 같은 탭에서 IAM 액세스 키 만들기 | `ce:GetCostAndUsage` 하나 | 조회 1번 $0.01(사용자 AWS 계정에 청구). 자동은 하루 1번만 → 한 달 약 $0.30, "지금 갱신"은 누를 때마다 $0.01 |
| Azure | **B** Microsoft 로그인 | Microsoft 로그인 창 | 구독의 Cost Management 읽기 권한자 | 없음 |
| OpenAI | **A** 화면 열기 + 완료 화면 읽기(미리 채우기 없음) + D | Admin keys 화면 | 조직 Owner가 만든 관리자 키(`sk-admin-`) | 없음 |
| Cloudflare | **A** 권한 미리 채우기 + D | API 토큰 만들기(Account · Billing · Read를 채우는 주소) | Account · Billing · Read | 없음 |
| GitHub | **A** 권한 미리 채우기 + D, 앱 ID가 있으면 **B** GitHub 로그인 | Fine-grained 토큰 만들기(Plan 읽기, 조직이면 Administration 읽기) | Plan: Read-only (조직은 관리자) | 없음 |
| Vercel | **A** 화면 열기 + 완료 화면 읽기(미리 채우기 없음) + D | Account Tokens 화면 | 팀에서 청구를 볼 수 있는 역할. 읽기 전용 토큰은 없음 | 없음 |

- **자동 받기가 안 될 때:** 실제 콘솔의 완료 화면 구조는 아직 실제 계정으로 확인하지 않았어요(가짜 화면 E2E로만 확인). 화면에 토큰 후보가 딱 하나일 때만 받고, 못 받으면 안내서대로 붙여 넣으면 돼요. 로그인·가입 화면과 비밀번호 칸은 읽지 않아요.
- **Cloudflare 권한 미리 채우기**는 공식 문서의 템플릿 주소 형식을 따랐지만 Billing 읽기가 실제로 채워지는지는 미확인이에요. 비어 있으면 Account → Billing → Read 하나만 직접 골라요.

### 아이디·비밀번호는 받지 않는 이유

| 이유 | 설명 |
|---|---|
| 권한이 전부예요 | 비밀번호는 읽기 전용이 아니에요. 새면 서버 삭제·결제까지 계정 전체가 넘어가요. 이 확장은 "읽기 전용 키만" 받는 게 원칙이에요. |
| 로그인이 자주 막혀요 | AWS·GitHub·Cloudflare 등은 MFA·캡차·새 기기 확인을 걸어요. 자동 로그인은 수시로 깨지고, 우회하면 봇 탐지에 걸려요. |
| 약관·심사에 걸려요 | 대부분 서비스 약관이 제3자에게 비밀번호를 맡기는 자동 로그인을 금지해요. 크롬 웹스토어도 남의 계정 비밀번호를 모으는 확장은 거절하거나 내려요. |
| 피싱과 구별이 안 돼요 | "여기에 AWS 비밀번호 넣으세요"는 피싱 화면과 똑같아요. 사용자에게 나쁜 습관을 들이게 해요. |

그래서 이미 로그인된 브라우저에서 사용자가 직접 읽기 전용 토큰을 만들게 하고(A·C·D), 로그인 연결은 서비스가 공식으로 주는 OAuth만 써요(B).

- **Cloudflare**는 계정 청구 내역(`/accounts/{id}/billing/history`)을 읽어요. 한 달에 한 번 청구되는 구조라 월말 예상은 지난달·이번 달 청구액 중 큰 값이에요.
- **GitHub**는 청구 사용량 보고서(`/settings/billing/usage`)의 `netAmount`를 더해요. GitHub의 새 청구 플랫폼(enhanced billing)을 쓰는 계정·조직만 돼요.
- **Vercel**은 청구 요금(`/v1/billing/charges`, FOCUS JSONL)의 `BilledCost`를 더해요. 요금제 결제·크레딧·조정은 월말 예상에서 늘려 잡지 않아요.
- 세 서비스는 공식 문서 형식대로 만든 가짜 응답으로만 검증했어요(`e2e/providers.e2e.mjs`). 실제 계정에서 다르게 나오면 알려 주세요.

- **언제 갱신되나:** 매일 아침 8시(`src/lib/cloud/config.js`의 `REFRESH_HOUR`). 그 시간에 브라우저가 꺼져 있었으면 켤 때, 팝업·대시보드를 열었을 때 6시간이 지났으면 다시 가져옵니다. **지금 갱신** 버튼도 있습니다.
- **실시간이 아닌 이유:** 세 서비스 모두 청구 데이터를 몇 시간~하루 늦게 집계합니다.
- **월말 예상:** 사용량은 이번 달 누적 ÷ 지난 날 수 × 이번 달 날 수, 요금제 같은 고정비는 그대로 더합니다. 단순 추정입니다.
- **원화:** [open.er-api.com](https://open.er-api.com) 환율(12시간마다)로 바꿉니다. 실패하면 달러 금액만 보입니다.
- **키 보관:** 키·토큰은 `chrome.storage.local`의 `cloudAccounts`에만 있고, 저장소는 확장 페이지·background만 읽을 수 있게(`TRUSTED_CONTEXTS`) 막아 둡니다. 오류 문장에 키가 되비쳐 나오면 가립니다. 화면은 금액만 담긴 `cloudCosts`를 읽습니다. 각 서비스 API 말고는 어디에도 보내지 않습니다. 컴퓨터 자체가 털리면 키도 노출되므로, 반드시 **읽기 전용** 키를 쓰세요.

### Azure 앱 등록 (배포자가 한 번만)

Azure 로그인 버튼을 쓰려면 이 확장을 Microsoft Entra 앱으로 등록해야 합니다. 비밀값은 필요 없습니다.

1. [Azure 포털 → Microsoft Entra ID → 앱 등록](https://portal.azure.com/#view/Microsoft_AAD_RegisteredApps/ApplicationsListBlade) → **새 등록**
   - 이름: `결제 기록장`
   - 지원되는 계정 유형: **모든 조직 디렉터리의 계정 및 개인 Microsoft 계정**
   - 리디렉션 URI: 플랫폼 **공용 클라이언트/네이티브(모바일 및 데스크톱)**, 값 `https://<확장 ID>.chromiumapp.org/azure`
     (확장 ID는 `chrome://extensions`에서 확인. 웹 스토어에 올리면 ID가 바뀌니 그 주소도 추가)
2. **API 사용 권한 → 권한 추가 → Azure Service Management → 위임된 권한 `user_impersonation`**
3. 개요의 **애플리케이션(클라이언트) ID**를 `src/lib/cloud/config.js`의 `AZURE_CLIENT_ID`에 넣습니다.

> 앱을 "모바일 및 데스크톱"으로 등록하는 이유: "단일 페이지 앱"으로 하면 로그인이 24시간마다 풀립니다. 대신 Microsoft가 확장의 `Origin` 헤더를 거절하므로, background의 토큰 요청에서만 `declarativeNetRequest`로 Origin을 지웁니다(웹페이지 요청은 건드리지 않음 — E2E로 확인).

### GitHub App 등록 (배포자가 한 번만, 로그인 연결을 쓸 때)

`GITHUB_CLIENT_ID`가 비어 있으면 "GitHub 로그인으로 연결" 버튼 대신 안내만 보이고, 토큰 붙여넣기·자동 받기는 그대로 돼요.

1. [GitHub → Settings → Developer settings → GitHub Apps → New GitHub App](https://github.com/settings/apps/new)
   - 이름: `결제 기록장`, Homepage URL은 아무 주소나 괜찮아요. Webhook은 끄세요.
   - **Enable Device Flow**를 켜요(안 켜면 "기기 연결이 꺼져 있어요" 오류가 나요).
   - 권한: **Account permissions → Plan: Read-only** 하나만.
2. 조직 사용료도 보려면 그 조직에 앱을 설치하고 **Organization permissions → Administration: Read-only**를 추가해요.
3. 앱 화면의 **Client ID**를 `src/lib/cloud/config.js`의 `GITHUB_CLIENT_ID`에 넣어요. **Client secret은 만들지도 넣지도 마세요.** device flow는 토큰 받기·갱신 모두 비밀키가 필요 없어요.

로그인 토큰은 8시간, 갱신 토큰은 6개월 가요. 만료되면 확장이 갱신 토큰으로 새로 받고, 갱신도 안 되면 다시 로그인하라고 알려 줘요.

### AWS 템플릿 (선택)

`aws/readonly-cost-user.json`은 `ce:GetCostAndUsage`만 가진 IAM 사용자 하나를 만들어요(액세스 키·비밀키는 만들지 않고 출력에도 없어요). 공개 S3 버킷에 올리고 그 https 주소를 `config.js`의 `AWS_TEMPLATE_URL`에 넣으면 연결 버튼이 CloudFormation 빠른 생성 화면으로 열려요. 비어 있으면 템플릿 파일을 받아 직접 업로드하는 안내가 보여요. 배포할 때 "IAM 리소스 생성 확인"(`CAPABILITY_NAMED_IAM`)에 체크해야 해요.

### 크롬 동기화

설정 화면에서 **동기화**를 켜면 같은 구글 계정으로 크롬 동기화를 켠 기기끼리 기록·카드·설정을 맞춥니다(기본은 꺼짐). 기기마다 켜야 합니다.

- 연결 키·토큰과 사용료는 올리지 않습니다. 기기마다 다시 연결하세요.
- 한도는 전체 약 100KB, 512개입니다(지운 표시도 90일 동안 한 칸을 씁니다). 넘으면 설정 화면에 알리고, 기록은 각 기기에 그대로 남습니다.
- 같은 기록을 양쪽에서 고치면 나중에 고친 쪽이 남습니다. 한쪽에서 지우고 다른 쪽에서 고쳤으면 고친 기록을 살립니다. 설정은 양쪽이 모두 바뀌었으면 동기화된 값을 따릅니다.
- 켜기 전에 두 기기에서 같은 결제를 따로 적었다면 두 건이 됩니다.
- 90일 넘게 동기화하지 않은 기기에서는 그사이 지운 기록이 지워지지 않고 그 기기에 남을 수 있습니다(이미 맞춘 뒤 안 고친 기록은 다시 올리지 않습니다).
- 크롬은 기기 사이 전달 시점을 보장하지 않습니다. 새 기기에서는 크롬 동기화가 끝난 뒤에 켜는 것이 안전합니다.
- **업데이트 주의:** `key`가 없던 버전을 이미 설치해 썼다면, 이 버전에서 확장 ID가 바뀌어 기존 기록이 안 보입니다. 업데이트 **전에** 백업 파일을 받아 두고 업데이트 뒤 가져오세요. 연결 키는 다시 연결해야 합니다.
- 압축해제 설치에서도 확장 ID가 같도록 `manifest.json`에 `key`를 둡니다. `npm run pack`은 이 값을 빼고 묶습니다.

 확장프로그램을 삭제하면 기록도 지워지니 필요하면 설정 화면의 **백업 파일 받기**로 받아 두세요.

## 동작 방식

- `src/content.js`: 모든 페이지·iframe에서 카드번호 입력칸과 결제 버튼 클릭을 감지하고, 페이지 글자에서 금액·주기·구독 여부만 뽑아서 보냅니다.
- `src/background.js`: 탭 단위로 이벤트를 30분 동안 하나의 기록으로 합칩니다. 결제창 팝업이나 PG 리다이렉트도 원래 사이트 기록으로 묶습니다.
- `src/lib/detect.js`: 금액·주기·유형 판별 (할부·날짜 오인 방지 포함)
- `src/lib/ledger.js`: 병합, 합계 규칙(확인·이번 달·해지), 다음 결제일, CSV

## 한계

- **보안 키패드**를 쓰는 카드사 결제창은 카드번호를 읽지 못합니다. 기록은 남지만 카드 칸이 비어 있습니다.
- **앱 인증**(카카오페이·토스 앱 푸시, 앱카드) 결제는 실제로 완료됐는지 알 수 없습니다. 결제 버튼을 누른 시점에 기록합니다.
- 판별은 휴리스틱입니다. 틀린 기록은 대시보드에서 **수정**을 누르면 고칠 수 있고, 한 번 수정한 기록은 자동으로 덮어쓰지 않습니다.
- 과거 결제 내역은 없습니다. 이미 등록해둔 자동결제는 [페이인포](https://www.payinfo.or.kr)나 카드사 앱의 정기결제 조회로 확인한 뒤 **직접 추가**로 넣으세요.

## 서비스 로고와 상표 안내

빠른 추가 목록과 기록 표의 서비스 로고는 [Simple Icons](https://simpleicons.org)(CC0 1.0, 퍼블릭 도메인) SVG를 `icons/brands/`에 담아 쓴 거예요. 로고를 인터넷에서 불러오지 않아서 외부 요청이 없어요.

- 로고와 이름은 각 회사의 상표예요. 이 확장은 해당 회사와 관계가 없고 후원·보증을 받지 않았어요. 서비스를 알아보기 쉽게 하려는 용도로만 써요.
- 로고가 없는 서비스는 이름에서 만든 색의 글자 아바타로 보여 줘요.
- 다시 가져오려면: `npm pack simple-icons`로 받아 푼 뒤 `node scripts/fetch-brand-icons.mjs <푼 폴더>/package`. 카탈로그(`src/lib/catalog.js`)의 `BRANDS`에 있는 아이콘만 복사해요.
